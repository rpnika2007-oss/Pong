## Описание проекта

Учебный проект на Python реализует пинг-понг для двух игроков за одним компьютером. Игроки отбивают мяч ракетками, а за каждый пропуск мяча соперник получает очко. Движение объектов отображается на Canvas, кадры обновляются с помощью таймера Tkinter.

## Функциональные возможности

### Основной функционал

- Два игрока управляют ракетками с одной клавиатуры. Ракетки остаются в пределах поля.
- Мяч движется автоматически и отскакивает от ракеток и горизонтальных границ.
- После пропуска мяча соперник получает очко, а мяч и ракетки возвращаются в исходное положение. До следующей подачи проходит около секунды. В это время можно двигать ракетки.
- Матч заканчивается, когда один из игроков набирает пять очков. На поле появляется номер победителя.
- Игру можно приостановить, продолжить или сбросить с клавиатуры и с помощью кнопок. При переключении в другое окно матч автоматически ставится на паузу.

### Дополнительный функционал

- После каждого удара ракеткой скорость мяча увеличивается до заданного предела.
- Чем дальше мяч попадает от центра ракетки, тем круче угол отскока.
- Лёгкая, средняя и сложная настройки задают начальную скорость мяча при каждой подаче.
- Обе ракетки могут двигаться одновременно.
- Один таймер обновляет анимацию. Пауза, сброс и начало нового матча меняют состояние игры в том же цикле.

## Демонстрация работы программы

В окне размером 900 × 600 пикселей на тёмном поле расположены бирюзовая и персиковая ракетки, светлый круглый мяч и пунктирная центральная линия. Над полем виден крупный счёт обоих игроков. В верхней части окна находятся кнопки управления и список сложностей, в нижней — подсказка по клавишам. Сообщения о паузе и победе появляются поверх поля.

## Установка и запуск

1. Клонируйте репозиторий GitHub, подставив его адрес вместо заполнителя.

   ```console
   git clone "<URL_РЕПОЗИТОРИЯ_GITHUB>" pong_project
   ```

2. Перейдите в папку проекта.

   ```console
   cd pong_project
   ```

3. Создайте виртуальное окружение для своего компьютера. Если папку проекта передали вместе с `venv/`, сначала переместите старое окружение за пределы проекта. Интерпретатор и пути внутри окружения привязаны к исходному компьютеру.

   Windows

   ```powershell
   python -m venv venv
   ```

   macOS и Linux

   ```bash
   python3 -m venv venv
   ```

4. Активируйте виртуальное окружение.

   Windows, PowerShell

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

   Windows, командная строка

   ```bat
   venv\Scripts\activate.bat
   ```

   macOS и Linux

   ```bash
   source venv/bin/activate
   ```

5. Выполните установку по списку зависимостей. Файл содержит только комментарии, поэтому `pip` не установит дополнительные пакеты.

   ```console
   pip install -r requirements.txt
   ```

6. Запустите программу.

   ```console
   python main.py
   ```

## Управление

| Клавиша | Действие |
| --- | --- |
| W | Поднять ракетку игрока 1 |
| S | Опустить ракетку игрока 1 |
| ↑ | Поднять ракетку игрока 2 |
| ↓ | Опустить ракетку игрока 2 |
| Пробел | Приостановить или продолжить матч |
| R | Обнулить счёт и вернуться к экрану начала |

Перед началом матча выберите сложность и нажмите «Начать игру». Кнопка «Пауза» меняется на «Продолжить», пока игра приостановлена. Кнопка «Заново» выполняет то же действие, что и R. Сложность можно выбрать перед новым матчем.

В русской раскладке клавишам W, S и R соответствуют Ц, Ы и К.

```text
pong_project/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── test_main.py

```

| Файл или папка | Назначение |
| --- | --- |
| `.gitignore` | Исключает каталоги `__pycache__/` и файлы `*.pyc` |
| `README.md` | Описывает проект, запуск, управление и принцип анимации |
| `requirements.txt` | Фиксирует отсутствие сторонних зависимостей |
| `main.py` | Содержит весь код игры |
| `test_main.py` | Проверяет столкновения, подачу, таймер и обработку фокуса |
| `venv/` | Содержит локальное виртуальное окружение Python |

Проект небольшой, поэтому весь код помещается в одном файле. Внутри файла `GameModel` рассчитывает движение и счёт, `GameRenderer` отрисовывает состояние игры, а `App` связывает модель и отрисовку с окном, кнопками, клавиатурой и таймером. Этих границ между тремя классами достаточно для данного масштаба, дополнительное деление на модули не требуется.

По требованию преподавателя папка `venv/` не включена в корневой `.gitignore`. При повторном создании окружения Python 3.13 и новее может создать внутри него собственный файл `venv/.gitignore`. Если содержимое окружения должно быть видно Git, удалите этот автоматически созданный файл.

## Принцип работы анимации

1. На каждом шаге модель рассчитывает перемещение ракеток по нажатым клавишам и ищет ближайшее столкновение мяча со стеной или ракеткой.
2. При столкновении с верхней или нижней границей вертикальная скорость меняет знак. После любого отскока мяч продолжает движение в оставшееся время шага.
3. Для ракетки проверяется касание круга с её гранью или углом. Положение ракетки и угол отскока вычисляются в момент касания.
4. Для расчёта угла расстояние от центра ракетки до точки попадания делится на половину её высоты. Результат ограничивается диапазоном от −1 до 1 и умножается на максимальный угол 60°. Попадание в центр даёт горизонтальный отскок, выше центра — отскок вверх, ниже — вниз. Косинус и синус угла задают составляющие новой скорости.
5. Таймер Tkinter запрашивает обновление каждые 16 миллисекунд. Число шагов модели зависит от прошедшего времени. Если вызов задержался, выполняется до восьми шагов за обновление. Во время паузы игровое время останавливается.

## Пример использования

1. Запустите `python main.py` и выберите, например, среднюю сложность.
2. Нажмите «Начать игру». Мяч полетит из центра поля, а счёт начнётся с 0:0.
3. Первый игрок использует W и S, второй — ↑ и ↓. Оба могут перемещать ракетки одновременно.
4. Если мяч пройдёт за правую границу, очко получит игрок 1. За пропуск у левой границы очко получит игрок 2. После короткой паузы мяч полетит из центра.
5. Нажмите пробел, чтобы остановить движение. Повторное нажатие продолжит тот же розыгрыш.
6. Когда один из игроков наберёт пять очков, на поле появится сообщение о победе. Нажмите «Начать игру» для нового матча или R, чтобы вернуться к экрану начала с нулевым счётом.
