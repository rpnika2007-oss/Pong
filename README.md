## Описание проекта

Учебный проект на Python реализует пинг-понг для двух игроков за одним компьютером. Игроки отбивают мяч ракетками, а за каждый пропуск мяча соперник получает очко. Движение объектов отображается на Canvas, кадры обновляются с помощью таймера Tkinter.

## Функциональные возможности

### Основной функционал

- Два игрока управляют ракетками с одной клавиатуры. Ракетки остаются в пределах поля.
- Мяч движется автоматически и отскакивает от ракеток, верхней и нижней стенок.
- Когда мяч полностью покидает поле слева или справа, очко получает соперник.
- Матч заканчивается, когда один из игроков набирает пять очков. На поле появляется номер победителя.
- Матч можно начать кнопкой, а приостановить, продолжить или сбросить — клавишей или кнопкой.

### Дополнительный функционал

- После каждого удара ракеткой скорость мяча увеличивается до заданного предела.
- Чем дальше мяч попадает от центра ракетки, тем круче угол отскока.
- Лёгкая, средняя и сложная настройки задают начальную скорость мяча при каждой подаче.
- После обычного очка мяч и ракетки возвращаются в центр. До подачи проходит около секунды. В это время можно двигать ракетки.
- При переключении в другое окно игра автоматически встаёт на паузу.
- Обе ракетки могут двигаться одновременно. В русской раскладке работают Ц, Ы и К.
- Анимация использует фиксированный шаг моделирования и один таймер Tkinter.

## Демонстрация работы программы

В белом окне размером 900 × 600 пикселей расположено светло-розовое поле с пунктирной центральной линией и тёмно-розовым мячом. У игроков ракетки разных оттенков розового. Над полем в рамке виден счёт, окрашенный в цвет соответствующей ракетки. В верхней части окна находятся светло-розовые кнопки управления и список сложностей, в нижней — подсказка по клавишам. Сообщения о паузе и победе появляются поверх поля.

## Требования к системе

- Python 3.10 или выше.
- Windows, macOS или Linux с графической средой.
- Tkinter. В некоторых дистрибутивах Linux может потребоваться установить системный пакет `python3-tk`.
- Сторонние Python-зависимости отсутствуют.

## Установка и запуск

1. Клонируйте репозиторий GitHub.

   ```console
   git clone https://github.com/rpnika2007-oss/Pong pong_project
   ```

2. Перейдите в папку проекта.

   ```console
   cd pong_project
   ```

3. Создайте локальное виртуальное окружение. Если в папке проекта уже есть рабочее окружение, перейдите к активации. Если папка `venv/` пришла из репозитория и привязана к другому компьютеру, переместите склонированную папку `venv/` за пределы проекта перед созданием нового окружения.

   Windows

   ```powershell
   python -m venv venv
   ```

   macOS и Linux

   ```bash
   python3 -m venv venv
   ```

4. Активируйте виртуальное окружение.

   Windows PowerShell

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

   Windows Git Bash

   ```bash
   source venv/Scripts/activate
   ```

   macOS и Linux

   ```bash
   source venv/bin/activate
   ```

5. Выполните установку по списку зависимостей. Файл содержит только комментарии, поэтому `pip` не установит дополнительные пакеты.

   ```console
   pip install -r requirements.txt
   ```

6. Запустите программу.

   ```console
   python main.py
   ```

## Управление

| Клавиша или элемент интерфейса | Действие |
| --- | --- |
| W / Ц | Поднять ракетку игрока 1 |
| S / Ы | Опустить ракетку игрока 1 |
| ↑ | Поднять ракетку игрока 2 |
| ↓ | Опустить ракетку игрока 2 |
| Пробел, кнопка «Пауза» / «Продолжить» | Приостановить или продолжить матч |
| R / К, кнопка «Заново» | Обнулить счёт и вернуться к экрану начала |
| Кнопка «Начать игру» | Начать новый матч с нулевым счётом |
| Список «Сложность» | Выбрать начальную скорость мяча перед матчем |

Во время матча выбор сложности недоступен. При возврате в окно после автоматической паузы продолжите игру пробелом или кнопкой «Продолжить».

## Структура проекта

```text
pong_project/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── test_main.py
└── venv/
```

| Файл или папка | Назначение |
| --- | --- |
| `.gitignore` | Исключает каталоги `__pycache__/` и файлы `*.pyc` |
| `README.md` | Описывает проект, запуск, управление и принцип анимации |
| `requirements.txt` | Фиксирует отсутствие сторонних зависимостей |
| `main.py` | Содержит весь код игры |
| `test_main.py` | Проверяет столкновения, подачу, таймер и обработку фокуса |
| `venv/` | Содержит локальное виртуальное окружение Python |

Проект небольшой. Весь код игры находится в `main.py`, поэтому его удобно читать и запускать одной командой из корня проекта. Ответственность внутри файла разделена между тремя классами.

- `GameModel` хранит состояние матча и рассчитывает движение, столкновения и очки.
- `GameRenderer` рисует поле, ракетки, мяч, счёт и сообщения на холсте Tkinter.
- `App` создаёт окно, обрабатывает клавиатуру и кнопки и запускает цикл анимации.

По требованию преподавателя папка `venv/` доступна для учёта в Git. При создании окружения в Python 3.13 и новее параметр `--without-scm-ignore-files` позволяет избежать автоматического создания вложенного файла `venv/.gitignore`.

## Математическая модель и принцип анимации

1. Начало координат модели находится в левом верхнем углу поля. Ось X направлена вправо, ось Y — вниз. При отрисовке к Y добавляется высота области над полем.
2. Мяч задаётся координатами центра, радиусом и скоростями по двум осям. Косинус и синус угла дают горизонтальную и вертикальную составляющие скорости. За часть шага каждая координата меняется на соответствующую скорость, умноженную на прошедшее время.
3. Модель ищет ближайшее касание со стеной или ракеткой. При касании верхней или нижней стены вертикальная скорость меняет знак. После отскока мяч использует оставшееся время шага.
4. Для проверки ракетки модель рассчитывает движение мяча относительно неё. При касании грани центр мяча находится от неё на расстоянии радиуса. Для угла проверяется расстояние от центра мяча до вершины прямоугольника. Момент, когда это расстояние равно радиусу, находится по квадратному уравнению.
5. Угол отскока зависит от расстояния точки попадания до центра ракетки. В центре мяч отскакивает горизонтально, у краёв угол достигает 60°. Скорость увеличивается после каждого удара ракеткой до установленного предела. При подаче восстанавливается скорость выбранной сложности.
6. `after()` просит Tkinter вызвать обновление примерно через 16 мс. Монотонные часы измеряют прошедшее время, а модель расходует его порциями по 16 мс. После задержки программа может выполнить несколько шагов за одно обновление, максимум восемь. На паузе отсчёт игрового времени останавливается.

## Пример использования

1. Запустите `python main.py` и выберите, например, среднюю сложность.
2. Нажмите «Начать игру». Мяч полетит из центра поля, а счёт начнётся с 0:0.
3. Первый игрок использует W и S, второй — ↑ и ↓. Оба могут перемещать ракетки одновременно.
4. Если мяч пройдёт за правую границу, очко получит игрок 1. За пропуск у левой границы очко получит игрок 2. После короткой паузы мяч полетит из центра.
5. Нажмите пробел, чтобы остановить движение. Повторное нажатие продолжит тот же розыгрыш.
6. Когда один из игроков наберёт пять очков, на поле появится сообщение о победе. Нажмите «Начать игру» для нового матча или R, чтобы вернуться к экрану начала с нулевым счётом.
