## Описание проекта

«Пинг-понг» — учебная игра на Python и Tkinter для двух игроков за одним компьютером. Игроки отбивают мяч ракетками и получают очки за промахи соперника. Игровые объекты отображаются на холсте `Canvas`, а их положение обновляется по таймеру Tkinter.

## Функциональные возможности

### Основной функционал

- Оба игрока могут одновременно управлять ракетками с одной клавиатуры. Ракетки движутся вертикально в пределах игрового поля.
- Мяч движется автоматически и отскакивает от ракеток, верхней и нижней границ поля.
- Если мяч полностью пересекает боковую границу поля, очко получает игрок на противоположной стороне.
- Побеждает игрок, первым набравший пять очков. На поле появляется сообщение с его номером.
- Матч можно начать, приостановить, продолжить и сбросить.

### Дополнительный функционал

- Три уровня сложности задают скорость мяча при подаче.
- Угол отскока зависит от точки попадания, а скорость мяча после удара растёт до установленного предела.
- Если матч продолжается после начисления очка, мяч возвращается в центр поля, а ракетки — в исходное положение. До следующей подачи проходит около секунды. В это время ракетки можно перемещать.
- При потере фокуса окна матч автоматически приостанавливается.
- Для управления поддерживаются английская и русская раскладки клавиатуры.

## Демонстрация работы программы

В верхней части белого окна размером 900 × 600 пикселей расположены заголовок, светло-розовые кнопки управления и список уровней сложности. Под ними находится табло в рамке. Счёт каждого игрока окрашен в цвет его ракетки.

Игровое поле светло-розовое, с тёмно-розовой рамкой и пунктирной линией по центру. Тёмно-розовый мяч обведён тем же цветом, что и рамка поля. Левая ракетка малиново-розовая, правая — сливово-розовая. Под полем приведены подсказки по клавишам. В центре поля перед началом матча появляется подсказка, а во время игры там выводятся сообщения о следующей подаче, паузе и победе.

## Требования к системе

- Python версии 3.10 или новее.
- Windows, macOS или Linux с графической средой.
- Tkinter. В некоторых дистрибутивах Linux его устанавливают отдельно, например с помощью пакета `python3-tk`.
- Git для клонирования репозитория.

Игра использует стандартную библиотеку Python.

## Установка и запуск

1. Клонируйте репозиторий GitHub.

   ```bash
   git clone https://github.com/rpnika2007-oss/Pong.git pong_project
   ```

2. Перейдите в папку проекта.

   ```console
   cd pong_project
   ```

3. Создайте виртуальное окружение `venv/`. Если в проекте уже есть рабочее окружение, перейдите к следующему шагу. Если при клонировании получено окружение с другого компьютера, сначала переместите эту папку за пределы проекта.

   **Windows**

   ```powershell
   python -m venv venv
   ```

   **macOS и Linux**

   ```bash
   python3 -m venv venv
   ```

4. Активируйте виртуальное окружение командой для вашей оболочки.

   **Windows PowerShell**

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

   **Командная строка Windows (CMD)**

   ```bat
   venv\Scripts\activate.bat
   ```

   **Windows Git Bash**

   ```bash
   source venv/Scripts/activate
   ```

   **macOS и Linux**

   ```bash
   source venv/bin/activate
   ```

5. Выполните команду установки зависимостей. В `requirements.txt` есть только комментарии, поэтому дополнительных пакетов для игры устанавливать не требуется.

   ```console
   pip install -r requirements.txt
   ```

6. Запустите программу.

   ```console
   python main.py
   ```

## Управление

| Клавиша или элемент интерфейса | Действие |
| --- | --- |
| `W` (`Ц` в русской раскладке) | Переместить левую ракетку вверх |
| `S` (`Ы` в русской раскладке) | Переместить левую ракетку вниз |
| `↑` (стрелка вверх) | Переместить правую ракетку вверх |
| `↓` (стрелка вниз) | Переместить правую ракетку вниз |
| Клавиша «Пробел» (при фокусе на игровом поле) или кнопка «Пауза» / «Продолжить» | Приостановить или продолжить матч |
| `R` (`К` в русской раскладке) или кнопка «Заново» | Сбросить счёт и вернуться на начальный экран |
| Кнопка «Начать игру» | Начать новый матч с нулевым счётом |
| Список «Сложность» | Выбрать начальную скорость мяча перед матчем |

Уровень сложности можно выбрать до начала матча или после его завершения. Если игра приостановилась при переключении на другое окно, вернитесь в неё и продолжите матч.

В соответствии с техническими требованиями преподавателя каталог `venv/` не включён в корневой файл `.gitignore`. Виртуальное окружение используется для изоляции среды выполнения проекта.

Игра состоит из трёх классов.

- `GameModel` хранит состояние матча, рассчитывает движение и столкновения, ведёт счёт и определяет победителя.
- `GameRenderer` отображает игровое поле, ракетки, мяч, счёт и сообщения на холсте `Canvas`.
- `App` создаёт графический интерфейс, обрабатывает нажатия клавиш и кнопок, управляет состояниями матча и планирует обновления анимации.

Для небольшой учебной игры достаточно одного файла `main.py`. Разделение на классы помогает проследить путь от ввода до отрисовки, а игру можно запустить одной командой из корня проекта.

## Принцип работы анимации

1. **Движение мяча.** Начало координат находится в левом верхнем углу игрового поля. Ось X направлена вправо, ось Y — вниз. Мяч описывается координатами центра, радиусом и скоростью. Горизонтальную составляющую скорости рассчитывают через косинус угла, вертикальную — через синус. Скорость измеряется в пикселях за шаг. Чтобы узнать, на сколько сдвинется мяч по каждой оси, соответствующую составляющую скорости умножают на долю прошедшего шага.
2. **Столкновения.** Модель ищет ближайшее столкновение со стенкой или ракеткой в пределах текущего шага. При отскоке от верхней или нижней стенки вертикальная составляющая скорости меняет знак. При проверке ракетки учитывается её движение. Для попадания по грани центр мяча должен приблизиться к ней на расстояние радиуса. Для попадания по углу модель решает квадратное уравнение, чтобы найти момент, когда расстояние от центра мяча до угла равно радиусу. После отскока мяч продолжает движение в оставшееся время шага.
3. **Угол отскока и скорость.** При попадании в середину ракетки мяч отскакивает горизонтально. Чем ближе попадание к верхнему или нижнему краю, тем больше угол отскока. Его величина ограничена 60° относительно горизонтали. Скорость после удара увеличивается до установленного предела, а при следующей подаче возвращается к значению выбранного уровня сложности.
4. **Фиксированный шаг моделирования.** Tkinter планирует следующий вызов обновления через `after()` с задержкой 16 мс. Фактически прошедшее время измеряется монотонными часами. За каждые накопленные 16 мс модель выполняет один шаг. Если вызов задержался, за одно обновление может выполниться до восьми шагов. Во время паузы модель не продвигается.

## Тестирование

Тесты в `test_main.py` проверяют столкновения, подачу, определение победителя, работу таймера, обработку пробела и смену фокуса. Игровое окно при этом не открывается. Для запуска выполните в корне проекта следующую команду.

```console
python -m unittest -v
```

## Пример использования

1. Запустите `python main.py` и выберите, например, среднюю сложность.
2. Нажмите «Начать игру». При счёте 0:0 мяч полетит из центра поля.
3. Первый игрок управляет левой ракеткой клавишами `W` и `S`, второй — правой ракеткой клавишами `↑` и `↓`.
4. Если во время первого розыгрыша второй игрок пропустит мяч за правую границу, первый получит очко. Счёт станет 1:0, и примерно через секунду мяч снова полетит из центра.
5. При необходимости приостановите матч клавишей «Пробел» или кнопкой «Пауза». Продолжите игру той же клавишей или кнопкой «Продолжить».
6. Матч завершится, когда один из игроков наберёт пять очков. Чтобы сыграть снова, нажмите «Начать игру». Чтобы вернуться на начальный экран, нажмите `R` или кнопку «Заново».
